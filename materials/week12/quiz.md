# Week 12 Self-Check Quiz

Introduction to Computer Engineering (400507-001) · Week 12
This quiz is not graded. It checks what you remember. Try it alone,
without your notes. About 10 minutes.

---

1. What is a **general-purpose computer**?
   a) A machine built to do only one job, forever
   b) One machine that runs many different programs, for many different jobs
   c) A computer used only by scientists
   d) A computer with no software installed

2. Which one of these is a **fixed-purpose device**?
   a) A laptop
   b) A smartphone
   c) A microwave's timer
   d) A desktop computer

3. A hospital uses a computer to turn scan signals into a picture.
   Which field is this closest to?
   a) Office
   b) Scientific
   c) Entertainment
   d) Mobile

4. What does an **e-commerce** application mainly do?
   a) Edits photos and video
   b) Buys and sells things over the internet
   c) Draws a 3D game world
   d) Stores logic gate designs

5. Why might a company run a **simulation** instead of a real-world
   test?
   a) Simulations are always more fun
   b) Some real tests are too costly, or too dangerous
   c) Simulations never need a computer
   d) Real tests are always cheaper

6. True or false: "Every application domain needs a completely
   different kind of computer."

7. Name **three** of the six application domains covered this week.

8. **Short answer.** In two sentences or less, explain why the same
   laptop can do office work, and also play games.

---
---

## Answer Key

1. **b) One machine that runs many different programs, for many
   different jobs.**
2. **c) A microwave's timer.** It runs one program, forever.
3. **b) Scientific.** Medical imaging is part of scientific and
   medical computing.
4. **b) Buys and sells things over the internet.**
5. **b) Some real tests are too costly, or too dangerous.**
6. **False.** Most domains run on the same general-purpose design;
   only the software, and sometimes the hardware amount, changes.
7. **Any three:** office, creative, scientific, business,
   entertainment, mobile.
8. **Sample answer:** It is a general-purpose computer, not a
   fixed-purpose device. New software is enough to give it a brand
   new job.
