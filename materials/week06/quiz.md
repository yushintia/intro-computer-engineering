# Week 6 Self-Check Quiz

Introduction to Computer Engineering (400507-001) · Week 6
This quiz is not graded. It checks what you remember. Try it alone,
without your notes. About 10 minutes. This is separate from today's
graded Quiz 1.

---

1. Which one of these is **application software**?
   a) The operating system
   b) A photo editor
   c) The part that shares CPU time between apps
   d) The part that manages memory

2. Which one of these is **system software**?
   a) A web browser
   b) A messaging app
   c) The operating system
   d) A music player

3. A photo file is saved perfectly, but no photo app is installed.
   Can you view the photo?
   a) Yes, files always show themselves
   b) No, an app is needed to decode and show it
   c) Yes, but only in black and white
   d) No, the file must be deleted first

4. What does it mean for an app to "decode" a file?
   a) Delete the file to save space
   b) Turn stored bytes back into a picture, sound, or text
   c) Send the file over the internet
   d) Move the file to a different folder

5. Every time an app runs, it requests resources from the OS. Which
   of these is **not** one of those resources?
   a) Memory
   b) CPU time
   c) Storage access
   d) The user's name

6. True or false: "More installed apps always make a device faster."

7. Put these three steps in order: **app decodes the bytes**, **file
   sits in storage as bytes**, **app renders the picture on screen**.

8. **Short answer.** In two sentences or less, explain why VisiCalc
   is often called the first "killer app."

---
---

## Answer Key

1. **b) A photo editor.** It does one specific task for the user.
2. **c) The operating system.** It manages the whole machine, not one task.
3. **b) No, an app is needed to decode and show it.** Stored data alone is not usable yet.
4. **b) Turn stored bytes back into a picture, sound, or text.** That is what decoding means.
5. **d) The user's name.** Memory, CPU time, and storage access are real resources; a name is not.
6. **False.** More apps can use more memory and CPU time, which can slow a device down.
7. **File sits in storage as bytes → app decodes the bytes → app renders the picture on screen.**
8. **Sample answer:** VisiCalc was so useful that people bought the Apple II just to run it. It proved one great app could sell the hardware by itself.
