## Professor Answer Key — do not hand out this section

Accept any reasonable, well-explained answer. The goal is reasoning,
not only a single "correct" pick.

### Part A

1. **Application software.** A browser does one task for the user:
   showing web pages.
2. **System software.** The OS manages the whole device, not one
   single task for the user.
3. **Application software.** It does one task for the user: editing
   photos.
4. **System software.** Sharing memory between apps is exactly the
   OS's job, not an app's.
5. **Application software.** It does one task for the user: sending
   messages.
6. **Application software.** It does one task for the user: playing
   music.

### Part B

1. **Word processor.** Writing and editing text documents.
2. **Media player.** Playing video (or audio) files.
3. **Web browser.** Viewing pages on the internet.
4. **Photo editor.** Viewing and editing pictures.
5. **Messaging app.** Sending texts, photos, or calls.
6. **Game.** Entertainment the user directly controls.
