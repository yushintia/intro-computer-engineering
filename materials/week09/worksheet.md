# Week 9 Worksheet: Two Laptops, One Meter Apart

Introduction to Computer Engineering (400507-001) · Week 9
Work with a partner. There can be more than one correct answer.

Running story: two students sit side by side. One has a photo on her
screen. The other wants a copy, right now. There is no wire between
the two laptops. This worksheet builds the words you need to explain
how the photo could actually get across.

## Part B (차시 3, in-class, ~15 minutes)

### B1. Put the steps in order

A webpage loads in four steps. Number them 1 to 4, in the correct
order.

- ____ The server sends the page back, in packets.
- ____ You type a URL into your browser.
- ____ Your browser rebuilds the page and shows it.
- ____ The router finds the server's address.

### B2. Finish the photo story

Back to the two laptops. Fill in each blank with the best word:
**website · download · upload · offline**.

1. When the client laptop receives the photo, that is called a
   ______________________________________________.
2. If the server laptop sent the photo instead to a shared folder on
   the internet, that would be called an ______________________________________________.
3. A page like a class syllabus, made of many linked pages on one
   server, is called a ______________________________________________.
4. Before the two laptops joined the same wifi, each one was
   ______________________________________________, unable to reach any
   network at all.

## Professor Answer Key — do not hand out this section

### Part A

1. **Wifi.** Turning wifi on is joining a wireless network.
2. **IP address.** `192.168.1.5` is the number format for an address.
3. **Internet.** A server "in another country" means many networks,
   connected worldwide.
4. **Network.** Two connected devices, able to send/receive data,
   is the definition of a network.
5. **Router.** It sends data toward the correct address for every
   device on the home network.
6. **Server.** It stores and sends information when asked.
7. **Client.** It is the device asking a server for information.
8. **Packet.** One small piece of a message, sent on its own.
9. **Browser.** The app that asks a server for a webpage.
10. **URL.** The exact address that names one webpage.

Discuss answer (sample): "The two laptops had no shared **network**,
so neither one had an **IP address** the other could use to find it."

### Part B

**B1.** Correct order:
1. You type a URL into your browser.
2. The router finds the server's address.
3. The server sends the page back, in packets.
4. Your browser rebuilds the page and shows it.

**B2.**
1. Download (the client receives the photo).
2. Upload (sending data from a device to a server on the internet).
3. Website.
4. Offline.

Discuss answer (sample): "Typing the URL and showing the page happen
on our own laptop. Finding the address and sending packets back
happen out on the network, partly far away."
