# Week 9 Self-Check Quiz

Introduction to Computer Engineering (400507-001) · Week 9
This quiz is not graded. It checks what you remember. Try it alone,
without your notes. About 10 minutes.

---

1. What does an **IP address** let one device do?
   a) Run faster
   b) Be found by, and find, other devices
   c) Store more files
   d) Connect a cable

2. Which one of these best describes a **network**?
   a) One single, very powerful computer
   b) Devices connected together, so they can send and receive data
   c) A website with many pages
   d) A cable with no devices attached

3. Your browser is a **client**. What is a **server**?
   a) A far-away computer that stores and sends information
   b) The cable that connects two laptops
   c) A small piece of a message
   d) The exact address you type for a webpage

4. Why does a big file often arrive as many small pieces, instead of
   all at once?
   a) The network breaks every message into packets first
   b) The file is broken on purpose to stop copying
   c) Only small files are allowed on a network
   d) The router deletes part of every file

5. A message says "no internet connection" on every app on your
   phone, at the same time. Which layer is most likely the problem?
   a) One single app's own code
   b) The network
   c) The phone's screen
   d) The phone's battery

6. True or false: "Wifi and the internet are the same thing."

7. Put these four steps in order, from first to last: **the browser
   shows the page, you type a URL, the router finds the server's
   address, the server sends packets back**.

8. **Short answer.** In two sentences or less, explain what a client
   and a server each do, using the "sending a photo between two
   laptops" example from class.
