## Answer Key

1. **b) Be found by, and find, other devices.** That is what an
   address is for.
2. **b) Devices connected together, so they can send and receive
   data.** That is the definition of a network.
3. **a) A far-away computer that stores and sends information.** A
   server answers; a client asks.
4. **a) The network breaks every message into packets first.** Each
   packet can even travel a different path.
5. **b) The network.** Every app failing at once, with the same
   message, points to the connection, not any single app.
6. **False.** Wifi is only one wireless way to join a network; the
   internet is a much larger network of networks, and some networks
   use cables instead of wifi.
7. **You type a URL → the router finds the server's address → the
   server sends packets back → the browser shows the page.**
8. **Sample answer:** The client is the device that asks for the
   photo, like the laptop that wants a copy. The server is the
   device that holds the photo and sends it, broken into packets, to
   the client.
9. **b) Modem.** It sits between the home network and the wider
   internet, converting data for the provider's line.
10. **b) A LAN covers one limited space; a WAN covers a wide
    geographic area.** A LAN might be one classroom's wifi; a WAN is
    the whole internet.
11. **a) It turns an easy-to-remember website name into a numeric IP
    address.** DNS works like a phonebook.
12. **c) 3G.** It added real, if slow, mobile internet access.
13. **False.** Fiber-optic sends data as pulses of light through
    glass or plastic, not electrical signals over copper.
14. **b) Interactive and social; ordinary users post, comment, and
    share.** That is Web 2.0.
