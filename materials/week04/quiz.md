# Week 4 Self-Check Quiz

Introduction to Computer Engineering (400507-001) · Week 4
This quiz is not graded. It checks what you remember. Try it alone,
without your notes. About 10 minutes.

---

1. What does a **CPU** do?
   a) Keeps data forever, even with no power
   b) Reads instructions and carries each one out, one at a time
   c) Connects your laptop to wifi
   d) Only shows images on the screen

2. Put these three cycle steps in the correct order: **execute,
   fetch, decode.**

3. Which CPU part does math and comparisons, like adding two numbers?
   a) The control unit
   b) A register
   c) The ALU
   d) The clock

4. Which CPU part directs each step, telling the other parts what to
   do next?
   a) The ALU
   b) The control unit
   c) A register
   d) A core

5. What is a **register**?
   a) A part that stores data forever, with no power
   b) A tiny, very fast storage spot inside the CPU
   c) A part that connects to the internet
   d) The steady beat that times each step

6. Your laptop's spec sheet says "3 GHz." What does this mean?
   a) The chip has 3 cores
   b) The clock ticks 3 billion times a second
   c) The laptop can run 3 apps at once
   d) The screen refreshes 3 times a second

7. True or false: "A faster CPU always fixes a slow app."

8. **Short answer.** A calculator app shows the wrong answer. Name one
   CPU part, or one step, that could explain why. Explain in one
   sentence.

---
---

## Answer Key

1. **b) Reads instructions and carries each one out, one at a time.**
   A CPU cannot think; it only follows exact steps.
2. **Fetch, decode, execute.** The CPU repeats this order, without
   stopping, until the program ends.
3. **c) The ALU.** It does the math and comparisons, using logic
   gates.
4. **b) The control unit.** It directs every step of the cycle.
5. **b) A tiny, very fast storage spot inside the CPU.** Registers
   hold data the CPU is using right now.
6. **b) The clock ticks 3 billion times a second.** "GHz" measures
   how many cycles happen every second.
7. **False.** A slow app can also be a software problem, not a CPU
   problem.
8. **Sample answer:** The ALU could have done the math step wrong, or
   the program could have sent the CPU the wrong instruction.
