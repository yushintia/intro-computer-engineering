# Week 7 Self-Check Quiz

Introduction to Computer Engineering (400507-001) · Week 7
This quiz is not graded. It checks what you remember. Try it alone,
without your notes. About 10 minutes.

---

1. What does an **operating system (OS)** do?
   a) It runs only one app, forever
   b) It manages hardware and shares it fairly among apps
   c) It is a piece of hardware inside the CPU
   d) It only manages the screen

2. What is a **process**?
   a) A type of hardware
   b) One program while it is running
   c) A device driver
   d) A fixed schedule of turns

3. Why can your laptop run five apps with only one CPU?
   a) Each app uses a different, hidden CPU
   b) The OS switches between apps very fast, using short time slices
   c) Only one app is ever really running; the rest are paused forever
   d) Apps do not need the CPU to run

4. Why can one app's memory not be seen by another app?
   a) Each process gets its own private memory space
   b) Memory is shared freely between all apps
   c) Only the OS has any memory at all
   d) Apps do not use memory

5. What is a **device driver** for?
   a) It lets the OS talk to one piece of hardware
   b) It schedules which process runs next
   c) It is another name for a process
   d) It stores an app's private memory

6. True or false: "Multitasking means every app truly runs at the
   exact same instant."

7. A video call's audio requests often get **priority** over a file
   download's requests. Explain, in one sentence, why.

8. **Short answer.** One app crashes, but every other open app keeps
   running fine. In two sentences or less, explain why, using an idea
   from this week.
