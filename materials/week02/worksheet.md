## Professor Answer Key — do not hand out this section

Accept any reasonable, well-explained answer for the "why" and
discussion lines.

### Part A

1. **1st generation.** ENIAC (1945) used vacuum tubes.
2. **4th generation.** A whole CPU on one chip is a microprocessor.
3. **2nd generation.** The transistor, invented 1947, defines this
   generation.
4. **3rd generation.** Integrated circuits (1958 onward) made
   desk-sized computers possible.
5. **3rd generation.** Packing many transistors onto one chip is the
   integrated circuit.
6. **1st generation.** Room-sized and prone to overheating describes
   vacuum-tube machines.

### Part B

**Section 1:**
1. **5 → `00000101`** (4 + 1)
2. **9 → `00001001`** (8 + 1)
3. **12 → `00001100`** (8 + 4)

**Section 2:**
4. Order: **ENIAC (1) → transistor (2) → integrated circuit (3) →
   microprocessor (4)**.
5. **2 → `00000010`**.
6. **Disagree/false.** Each position has a fixed, doubling value, so
   the order of digits changes what number it represents.
