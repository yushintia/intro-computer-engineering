# Week 10 Self-Check Quiz

Introduction to Computer Engineering (400507-001) · Week 10
This quiz is not graded. It checks what you remember. Try it alone,
without your notes. About 10 minutes.

---

1. What is a **programming language**?
   a) A spoken human language, like English
   b) A set of exact rules for writing instructions a computer can follow
   c) A type of computer chip
   d) A way to connect two laptops over wifi

2. What is **code**?
   a) A secret message between two computers
   b) Instructions written in a programming language
   c) A type of computer virus
   d) The physical wires inside a laptop

3. Mia's laptop repeats the same rename steps for all 200 photos.
   Which building block is this?
   a) Sequence
   b) Loop
   c) Decision
   d) Translator

4. A program checks a photo's name and skips it if the name is
   already used. Which building block is this?
   a) Sequence
   b) Loop
   c) Decision
   d) Bug

5. What does a **translator** (compiler or interpreter) do?
   a) Changes code into instructions a chip can run
   b) Writes code for the programmer automatically
   c) Connects a laptop to the internet
   d) Stores files permanently on a hard drive

6. True or false: "A computer understands plain English just as well
   as exact code."

7. Name the **three basic building blocks** used in every program.

8. **Short answer.** In two sentences or less, explain why Mia's photo
   task needs a loop, not just a sequence.

9. Which line below is written in **assembly language**?
   a) `10110000 00000101`
   b) `ADD A, 5`
   c) `total = total + 5`
   d) `SELECT * FROM Photos`

10. Which statement correctly distinguishes a **compiler** from an
    **interpreter**?
    a) A compiler translates all the code first, before running; an interpreter translates one line at a time, while running
    b) An interpreter translates all the code first, before running; a compiler translates one line at a time, while running
    c) They both translate code at exactly the same moment
    d) Neither one actually translates code

11. In the "Compiling vs. Interpreting Mia's Script" example, her
    **interpreted** version has a typo on line 150. What happens?
    a) The program refuses to run at all, before touching any photo
    b) The first 149 photos may already be renamed before it crashes
    c) The typo is automatically fixed
    d) Nothing happens; interpreters ignore typos

12. In `CLASS Photo ... END CLASS`, what is `Photo`?
    a) One specific object
    b) A class: the blueprint describing what an object of that kind will contain
    c) A method
    d) A bug

13. What is a **method**, in object-oriented programming?
    a) A type of loop
    b) An action defined inside a class, that an object of that class can perform
    c) A mistake in code
    d) A translator

14. Compared to a 3GL like Python or C, what makes SQL a **4GL**?
    a) It requires more explicit loops and decisions
    b) It lets a person describe what result they want, without spelling out how to compute it
    c) It only runs on one specific chip
    d) It cannot be used to ask questions of data

15. Which of **HTML, CSS, or JavaScript** defines a webpage's
    behavior: what happens when you click or type?
    a) HTML
    b) CSS
    c) JavaScript
    d) None of them

16. A program is missing an `END FOR`, and the translator refuses to
    run any of it. This is a:
    a) Logic error
    b) Syntax error
    c) Correctly running program
    d) Compiler
