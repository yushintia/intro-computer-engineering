## Professor Answer Key — do not hand out this section

Accept any reasonable, well-explained answer. The goal is reasoning,
not a single "correct" pick.

### Part A

1. **Memory.** Not saved yet, so it only exists in RAM while the
   program runs.
2. **Storage.** Saved yesterday, so it lives permanently in storage.
3. **Storage.** Installed but not open, so it sits in storage, not
   loaded into memory.
4. **Both.** The game itself is stored as a file, but the level you
   are actively playing is loaded into memory to run quickly.
5. **Storage.** Downloaded means it was saved, so it survives without
   the internet or power cycling.
6. **Memory.** Not saved anywhere, so it only exists in RAM until the
   app closes or crashes.

### Part B

1. **Gone.** Never saved, so it only existed in memory, which emptied
   when the laptop crashed.
2. **Survives.** The save five minutes ago copied it into storage,
   which does not need power to keep data.
3. **Survives.** Installing a new app writes it to storage; a restart
   only clears memory, not storage.
4. **Gone.** With no auto-save and no manual save, the message only
   ever existed in memory.
5. **Mostly survives.** The movie file itself is safe in storage,
   because it was downloaded (saved) earlier. Only unsaved things
   like your exact pause position may be lost. Accept reasoning about
   which part survives and which does not.
6. **False.** Both are technically fast because they use chips, but
   SSD is storage (non-volatile, keeps data with no power) while RAM
   is memory (volatile, needs constant power). They do different
   jobs.
