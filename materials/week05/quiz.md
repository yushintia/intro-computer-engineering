# Week 5 Self-Check Quiz

Introduction to Computer Engineering (400507-001) · Week 5
This quiz is not graded. It checks what you remember. Try it alone,
without your notes. About 10 minutes.

---

1. Which one of these is **memory (RAM)**, not storage?
   a) A saved photo
   b) An installed app
   c) Data in a program you have open right now
   d) A downloaded song

2. Which one of these is **storage**, not memory?
   a) A document you have not saved yet
   b) A saved file on your hard drive
   c) Numbers in an open, unsaved calculator
   d) Text typed but not yet saved

3. What does **volatile** mean?
   a) It keeps its data forever, even with no power
   b) It loses its data as soon as power stops
   c) It is a kind of storage, not memory
   d) It means "very fast"

4. Your laptop crashes while you are editing a document you saved two
   minutes ago. What happens?
   a) Everything since you opened the file is lost
   b) Nothing is lost; storage keeps the saved version
   c) The whole storage drive is erased
   d) The document turns into a photo

5. What is the difference between an **HDD** and an **SSD**?
   a) They are the same thing
   b) HDD uses a spinning disk; SSD uses chips with no moving parts
   c) HDD is memory; SSD is storage
   d) SSD cannot keep data with no power

6. True or false: "Bigger storage always means a faster computer."

7. Put these three in order, from **fastest** to **slowest**: HDD,
   RAM, SSD.

8. **Short answer.** In two sentences or less, explain why unsaved
   work disappears when the power stops, but saved files do not.

9. Put these four rungs of the memory hierarchy in order, from
   **fastest** to **slowest**: Cache, Secondary storage, RAM, Registers.

10. A cache hit takes about 1 ns, and a cache miss takes about 100 ns.
    If 9 out of 10 requests are hits, the average request time is
    closest to:
    a) 1 ns
    b) 11 ns
    c) 50 ns
    d) 100 ns

11. Which of these correctly describes **ROM**?
    a) It is volatile and holds the operating system
    b) It is non-volatile and holds fixed firmware, rarely rewritten
    c) It is exactly the same thing as an SSD
    d) It gets rewritten every time you save a file

12. Why does a drive advertised as "256GB" often show up as only
    about 238GB in your file explorer?
    a) Some of the storage is broken
    b) The manufacturer uses powers of 10, but the OS reports using powers of 2
    c) The missing space was deleted by mistake
    d) The drive is actually smaller than advertised

13. What is the difference between **access time** and **throughput**?
    a) They are the same measurement, with different names
    b) Access time is how long you wait for data to start arriving; throughput is how much data flows per second once it's moving
    c) Access time only applies to RAM; throughput only applies to storage
    d) Throughput is measured in nanoseconds, and access time is measured in GB/s
