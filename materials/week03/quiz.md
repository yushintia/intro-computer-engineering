# Week 3 Self-Check Quiz

Introduction to Computer Engineering (400507-001) · Week 3
This quiz is not graded. It checks what you remember. Try it alone,
without your notes. About 10 minutes.

---

1. What is a **Boolean value**?
   a) Any number a computer can store
   b) A value that can only be true or false
   c) A value between 0 and 100
   d) The name of a computer chip

2. An **AND gate** has inputs true and false. What is the output?
   a) True
   b) False
   c) Both true and false
   d) Neither true nor false

3. An **OR gate** has inputs false and true. What is the output?
   a) True
   b) False
   c) It depends on the gate's brand
   d) Neither true nor false

4. A **NOT gate** has one input: true. What is the output?
   a) True
   b) False
   c) The same as the input, unchanged
   d) There is no output

5. "Bring umbrella = 'Raining' AND 'No umbrella at home.'" It is
   raining, and you already have an umbrella at home. Do you bring one?
   a) Yes, because it is raining
   b) No, because not every input is true
   c) Yes, because OR only needs one true input
   d) It cannot be decided

6. Why do computer chips use only two values (on/off), not five or ten?
   a) Two values are cheaper to advertise
   b) Two states, far apart, are hard to confuse with each other
   c) Computers cannot count past two
   d) There is no real reason, it is just tradition

7. True or false: "A logic gate can change its rule depending on the situation."

8. **Short answer.** In two sentences or less, explain the difference
   between an AND gate and an OR gate.
