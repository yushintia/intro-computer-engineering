# Week 11 Self-Check Quiz

Introduction to Computer Engineering (400507-001) · Week 11
This quiz is not graded. It checks what you remember. Try it alone,
without your notes. About 10 minutes.

---

1. What is a **database**?
   a) A single file on a hard drive
   b) An organized collection of data a program can search
   c) A picture of a computer chip
   d) Another name for a password

2. In a database table, what is one **row** also called?
   a) A field
   b) A column
   c) A record
   d) A query

3. In a database table, what is one **column** also called?
   a) A field
   b) A record
   c) A row
   d) A password

4. What does a **query** do?
   a) It locks an account with a password
   b) It asks the database a question, and returns matching rows
   c) It deletes an entire table
   d) It scrambles data so no one can read it

5. Which password is the **strongest**?
   a) "123456"
   b) "password"
   c) "Su3#kL9!qzT2"
   d) "12345678"

6. What does **encryption** do?
   a) It groups rows and counts them
   b) It scrambles data, so only the right person can read it
   c) It deletes old records automatically
   d) It makes a table load faster

7. True or false: "A short, simple password is fine, as long as you
   remember it easily."

8. **Short answer.** In two sentences or less, explain why Mia's
   photo app needs both a database and a password, not just one.

---
---

## Answer Key

1. **b) An organized collection of data a program can search.**
2. **c) A record.** A row is one single entry in a table.
3. **a) A field.** A column is one piece of information.
4. **b) It asks the database a question, and returns matching rows.**
5. **c) "Su3#kL9!qzT2".** It is long, and mixes letters, numbers, and symbols.
6. **b) It scrambles data, so only the right person can read it.**
7. **False.** An easy-to-remember password is often also easy for
   others to guess.
8. **Sample answer:** The database stores and organizes Mia's data,
   but a password is needed too, so only Mia can see or change it.
