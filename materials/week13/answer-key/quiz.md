## Answer Key

1. **b) Software that learns patterns from examples.** That is the core definition of AI.
2. **b) Showing a computer many labeled examples, so it can learn.** That is training.
3. **b) The learned pattern an AI built from its training examples.** That is a model.
4. **b) The model made a wrong best guess, a normal AI error.** A wrong guess is not a broken app.
5. **a) When training data is unfair or incomplete, so guesses are less fair too.** That is bias.
6. **False.** It usually traces back to unfair or incomplete training data, not random luck.
7. **Labeled examples → training → model → prediction.**
8. **Sample answer:** A model only recognizes patterns it saw during training. A new, unusual photo can differ enough from those patterns to cause a wrong guess.
