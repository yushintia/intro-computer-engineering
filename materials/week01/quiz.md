# Week 1 Self-Check Quiz

Introduction to Computer Engineering (400507-001) · Week 1
This quiz is not graded. It checks what you remember. Try it alone,
without your notes. About 10 minutes.

---

1. Which one of these is **hardware**, not software?
   a) An app
   b) The operating system
   c) The CPU
   d) A program

2. Which one of these is **software**, not hardware?
   a) The screen
   b) The battery
   c) The camera
   d) An app

3. What does the **CPU** do?
   a) Stores data forever, even with no power
   b) Runs instructions, one at a time
   c) Connects the device to wifi
   d) Displays images on the screen

4. A video call freezes but everything else on the phone works fine.
   Which layer is **most likely** the problem?
   a) Hardware
   b) The video-call app (software)
   c) The battery
   d) The screen

5. What is the difference between **memory** and **storage**?
   a) They are the same thing
   b) Memory holds data only while running; storage keeps data with no power
   c) Memory is software; storage is hardware
   d) Storage is faster than memory

6. True or false: "A phone with no software can still run apps."

7. Put these in order, from what you see first (top) to the physical
   chip (bottom): **CPU, application software, logic gates, operating
   system**.

8. **Short answer.** In two sentences or less, explain why restarting
   a frozen device often fixes the problem, even when nobody knows
   which layer failed.

---
---

## Answer Key

1. **c) The CPU.** It is a physical chip — hardware.
2. **d) An app.** Apps are software; you cannot touch them.
3. **b) Runs instructions, one at a time.** That is the CPU's job.
4. **b) The video-call app (software).** Everything else working
   points away from hardware, OS, or the whole device.
5. **b) Memory holds data only while running; storage keeps data with
   no power.**
6. **False.** Software is required for hardware to do anything
   useful; hardware alone cannot run apps.
7. **Application software → operating system → CPU → logic gates.**
8. **Sample answer:** Restarting resets every layer at the same time.
   Whichever layer had the problem, hardware, software, OS, or
   network, starts fresh again.
