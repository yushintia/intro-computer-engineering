# Key Words Today

- **Binary** — a number system using only two digits: 0 and 1.
- **Digit** — a single symbol used to write a number, like 0-9.
- **Decimal** — the number system we use daily, with ten digits.
- **Bit** — one binary digit, either a 0 or a 1.
- **Place value** — how much a digit is worth, based on its position.

# Where the First Computer Came From

<div class="thread">You just felt the pain. Where did the history begin?</div>

- **1940s, World War II:** armies needed fast, correct artillery calculations.
- **Human "computers":** people calculated these tables by hand, slowly, with errors.
- **1945:** ENIAC, the first electronic computer, was built to solve this exact problem.

<div class="why">
This is why computers exist at all. A slow, human task with many
mistakes needed a faster machine.
</div>

---

<!-- SLOT 9: Core concept -->

# Binary Number System: Definition

<div class="thread">Now meet the number system computers use underneath.</div>

> A **binary number system** uses only two digits, **0** and **1**, to
> write any number.

- **Decimal** (what we use daily) has ten digits: 0 through 9.
- **Binary** has only two digits: 0 and 1.

Every number you know in decimal also has a matching binary form.

# What Changed Each Generation

| Generation | Built From | Size | Speed |
|---|---|---|---|
| 1st (1940s) | Vacuum tubes | Filled a room | Very slow |
| 2nd (1950s) | Transistors | Filled a cabinet | Faster |
| 3rd (1960s) | Integrated circuits | Fit on a desk | Much faster |
| 4th (1970s+) | Microprocessors | Fits in your hand | Fastest yet |

Each generation got smaller, faster, and cheaper than the one before.

# Binary Basics: Place Values

<div class="thread">Binary digits are not random. Each position has a fixed value.</div>

| Place value | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|---|
| Example digit | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 1 |

Each position is worth double the value to its right.

---

# Converting Decimal to Binary

<div class="thread">One method: check each place value, biggest to smallest.</div>

**Example: convert 13 to binary.**

- 128? No. 64? No. 32? No. 16? No.
- 8? Yes → 13 − 8 = 5.
- 4? Yes → 5 − 4 = 1.
- 2? No.
- 1? Yes → 1 − 1 = 0.

**Result: 13 in decimal is `00001101` in binary.**

# Case Study: History Inside Your Laptop

<div class="thread">Same laptop from Week 1. Now look at its history.</div>

- Your laptop's CPU is a **microprocessor** — 4th generation technology, from 1971 onward.
- Its ancestor, ENIAC, filled a whole room. Yours fits in a bag.
- Say your laptop has **4 CPU cores**. In binary, 4 is `00000100`.

This one small number already uses the system every chip runs on.

<!-- SLOT N-1: Common mistakes -->

# Common Mistakes

- **"Old computers were just slower versions of today's":** Wrong. They used completely different technology, like tubes instead of chips.
- **"Binary digits can be in any order":** Wrong. Each position has a fixed, doubling value.
- **"Only computers use binary":** Wrong. Phones, watches, and thermostats use it too.
