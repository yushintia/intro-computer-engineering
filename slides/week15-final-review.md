# Questions 1-2: Weeks 1-7, Quick Refresh

1. Put these three CPU steps in order: decode, execute, fetch.
2. True or false: memory (RAM) keeps its data with no power.

<!-- notes: These weeks were already covered in the Week 8 midterm review. Move through them quickly. -->

---

# Answers 1-2

1. **Fetch → decode → execute.**
2. **False.** Memory loses its data with no power. Storage does not.

---

# Questions 3-4: Week 9, Computer & Internet

3. What does an IP address let one device do?
4. In a browser and a website, which one asks the question: client or server?

---

# Answers 3-4

3. It lets a device find, and be found by, other devices.
4. The **client** asks. The **server** holds and sends the answer.

---

# Questions 5-6: Week 10, Programming Language

5. Name the three building blocks of any program.
6. What does a translator (compiler or interpreter) do to code?

---

# Answers 5-6

5. **Sequence, loop, and decision.**
6. It changes code a person wrote into signals a chip can run.

---

# Questions 7-9: Week 11, Databases & Security

7. In a simple data table, what does one row usually hold?
8. Name the short language people use to ask a database a question.
9. Name one simple way to keep your account safe from strangers.

---

# Answers 7-9

7. **One record**, like one student, one product, or one order.
8. **SQL.** It lets a person ask a database for exact data.
9. A strong, private password. Never share it with anyone else.

---

# Questions 10-11: Week 12, Computer Applications

10. Give one example of application software used for multimedia.
11. Name one everyday task a mobile app helps you finish.

---

# Answers 10-11

10. Sample: a photo editor, a music player, or a video app.
11. Sample: banking, messaging, navigation, or ordering food.

---

# Questions 12-13: Week 13, AI

12. What does an AI model need a lot of, before it predicts well?
13. True or false: a trained AI model can still be wrong.

---

# Answers 12-13

12. **Training data.** More good data usually means better predictions.
13. **True.** A trained model can still make mistakes, even after training.

---

# Questions 14-15: Week 14, Emerging Technologies

14. Name one example of a new, still-changing technology.
15. Why do computer engineers keep learning after this course ends?

---

# Answers 14-15

14. Sample: the Internet of Things, quantum computing, or wearable devices.
15. Technology keeps changing. Today's newest idea will not stay newest for long.
