<!-- SLOT 8: Origin -->

# Where This Idea Came From

<div class="thread">You just felt the pain. Where did the answer come from?</div>

- **1940s:** early computers were built for one job only, like calculating artillery paths.
- **1945:** John von Neumann described a machine that stores its program, not only its data.
- A program is just stored data too. So one machine can load a new program, and get a new job.

<div class="why">
This idea is why Mia's laptop writes essays, edits photos, and
plays games. Same hardware. Different stored programs.
</div>

---

<!-- SLOT 9: Core concept -->

# General-Purpose Computer: Definition

<div class="thread">One idea, one clear definition.</div>

> A **general-purpose computer** is a machine for many different
> jobs, not just one.

- It is not built for one task only, unlike a microwave's timer.
- New software is enough to give it a brand new job.

---

<div class="thread">One idea, four big steps.</div>

- **General-purpose computer** — one machine that runs many different jobs.
- **Application domain** — a real-world field that uses computers, like healthcare.
- **Specialized software** — a program built for one particular field.
- **Fixed-purpose device** — a machine built to do only one job, forever.

- A word processor helps you write and edit an essay.

# Zoom In: Creative Tools

<div class="thread">Turning raw files into finished work.</div>

- A video editor cuts and joins clips, into one finished video.
- A music program records and mixes sound, track by track.
- Editing large video files needs a fast CPU, from Week 4.
- It also needs plenty of memory, from Week 5, while you work.

---

# Zoom In: Scientific & Medical Tools

<div class="thread">Computers model things a person cannot see directly.</div>

- A weather program runs a **simulation**: a model of tomorrow's sky.
- A hospital scanner turns signals from your body into an image.
- A doctor studies that image on a computer screen, not on film.
- Both fields save huge amounts of data, in careful databases.

---

# Why Simulate Instead of Test for Real?

<div class="thread">Some real-world tests are too costly, or too dangerous.</div>

- Crashing a real car tests one safety design, and destroys the car.
- A computer simulation crashes a virtual car, many times, safely.
- Weather and disease models predict danger, before it actually happens.

Simulations save money, time, and sometimes lives.

---

# Zoom In: Entertainment

<div class="thread">The field built for fun, not just for work.</div>

- A game draws a whole 3D world, many times every second.
- Fast drawing needs a fast CPU, and often a graphics chip too.
- A streaming app sends video over a network, as you watch it.
- Networks, from Week 9, must keep that video arriving on time.

---

# Zoom In: Mobile Computing

<div class="thread">The same jobs, but small enough for your pocket.</div>

- Your phone has an **embedded computer**, built right into the device.
- **Mobile computing** means you carry that computer everywhere you go.
- Good apps are **cross-platform**: built to run on a phone or a laptop.
- The six layers stay the same. Only the size changes.

---

# One App, Many Fields

<div class="thread">Some software crosses fields, instead of staying in one.</div>

- A spreadsheet plans a budget in an office, and tracks lab results in science.
- A database, from Week 11, holds patient records, and also holds store inventory.
- A web browser reaches a bank, a hospital portal, or a game.

Specialized software fits one field best. Some general tools work almost everywhere.

<!-- SLOT N-1: Common mistakes -->

# Common Mistakes

- **"Each field needs a totally different kind of computer":** Wrong. Most run on the same general-purpose design.
- **"Only 'tech jobs' use computers":** Wrong. Hospitals, farms, and shops all depend on them too.
- **"Mobile computing is a separate field":** Wrong. It is the same jobs, on a smaller, portable device.
